# Legislação — textos oficiais (opcional)

Coloque aqui arquivos `.md` ou `.txt` com o texto oficial (ou resumos
detalhados) das normas usadas pelo Uai Sô:

- EC 108/2020
- Lei 14.113/2020
- Lei 18.030/2009 ("Lei Robin Hood")
- Lei 24.431/2023

Os textos oficiais podem ser obtidos em `planalto.gov.br` (leis federais e
emendas constitucionais) e `almg.gov.br` (leis estaduais de MG).

Após adicionar arquivos aqui, reconstrua o índice:

```bash
python -m src.ingestion.build_index
```
